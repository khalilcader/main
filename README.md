# khalilcader.com

Portfolio site for Khalil Cader.

## prototype/

`prototype/index.html` is an interaction prototype for the work strip: a row of
covers you can drag or scroll (with rubber banding at the ends), tap to open
full-size, pull down to close, and switch into a packed grid (press G). It's a
single file with no build step; open it in a browser.

The covers are placeholders. The "Values" panel shows live spring state and
has sliders for stiffness, damping, and rubber band strength.
